## 家宽IP、原生、双ISP分别是什么意思

三个词说的是同一件事的三个侧面。家宽IP指IP段由香港本地宽带运营商（比如 HGC、iCable 这类）分配给家庭用户使用；原生指IP注册地和使用地都在香港，落地不绕道；双ISP指这个IP在主流IP数据库里被标记为ISP（宽带运营商）属性，而不是hosting/数据中心属性。

平台风控查询的主要是最后一项。机房IP在数据库里带着hosting标签，风控系统可以直接限制功能或判定为代理；双ISP住宅IP则维持“住宅”标签，欺诈评分也更低。拿到IP之后，用常见的IP查询网站看一下ISP类型和欺诈分，几分钟就能验证商家宣传的真假。
